# AI Agent Skills

A curated collection of **88 skills** for AI coding/research agents 
(Claude-style `SKILL.md` format). Each folder is a self-contained skill: a `SKILL.md` 
plus optional `references/`, `scripts/`, `templates/` and `evals/`.

## Structure

- `SKILL_REGISTRY.md` — Tier-1 intent router for the Artemis assistant.
- `<skill-name>/SKILL.md` — the skill itself.

## Install

Copy the skill folders (and optionally `SKILL_REGISTRY.md`) into your agent's 
skills directory, then restart the agent. Each `SKILL.md` frontmatter declares 
the `name` and `description` used for routing.
