# Introduction Skeleton (EN)

Funnel structure:
1. **Broad context** — [field + significance; economic/natural framing
   only if warranted — never by default]
2. **Prior knowledge** — [2–4 citation-dense paragraphs; every prior-work
   claim cited; else [citation needed]]
3. **Gap** — [the methodological/analytical/coverage limitation this study
   addresses]
4. **This study** — [one compact paragraph: what was done + what it enables]

Voice: formal, information-dense; one move per paragraph.
