# Response-to-Reviewers Skeleton (EN)

Point-by-point; polite, non-defensive; changes located precisely.
- **Reviewer N, Comment k:** "[quoted comment]"
  **Response:** [direct answer first; evidence-calibrated]
  **Change made:** [what + where (section/paragraph/line)]; [new text quoted]
- **Global response:** [thanks + summary of major revisions]
- If disagreeing: [reasoning + evidence; offer alternative wording]
- New citations: [approved list only; else [citation needed]]
