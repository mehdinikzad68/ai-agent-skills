# Acceptance Checklist (final)

Run for every draft produced with this skill.

## Originality (qualitative rule)
- [ ] No intentional reproduction of distinctive wording and no close
      paraphrase of reference-corpus sources
- [ ] No distinctive corpus phrasing, data, results, methods specifics,
      citations, hypotheses, or conclusions transferred
- [ ] No collaged fragments; single consistent authorial voice
- [ ] Qualitative originality review performed unless an authorized
      similarity-analysis tool is available and has actually been used
- [ ] No claim of measured similarity, plagiarism scores, or a
      plagiarism-pass result without such a tool

## Evidence discipline
- [ ] Every factual claim comes from user-supplied verified input
- [ ] All gaps explicitly marked, in the draft's language:
      EN `[citation needed]` / `[data needed]` / `[method detail needed]` /
      `[author confirmation needed]`; FA `[نیازمند منبع]` /
      `[نیازمند داده]` / `[نیازمند جزئیات روش]` / `[نیازمند تأیید نویسنده]`
- [ ] No invented data, methods, citations, DOIs, policies, names,
      approvals
- [ ] Numbers, units, dispersion, n exactly as supplied; no new statistics
- [ ] No citations in the abstract unless the venue explicitly permits or
      requires them

## Claim calibration
- [ ] Strong data → direct wording; partial data → measured hedging
- [ ] No causal verbs without causal design; no generalization beyond scope
- [ ] Five layers separated and signaled where useful: result /
      interpretation / hypothesis / limitation / prospective application

## Structure & style
- [ ] Section architecture per venue or adjustable default (abstract
      structure follows venue when specified — never forced)
- [ ] When a venue requires a combined Results and Discussion section,
      preserve the venue structure while making observation, interpretation,
      limitation, and prospective application distinguishable
- [ ] Economic/quantitative framing used only where appropriate
      (Persian proposals / applied contexts), never auto-injected; basic
      plant-biotech/ecophysiology papers frame significance around
      biological, methodological, or monitoring value
- [ ] Reproducibility-level method detail where relevant
- [ ] Figure/table narration where relevant
- [ ] Register, tense, and transitions per section rules

## Declarations completeness
- [ ] Transparency/declarations block complete: Acknowledgements, Author
      Contributions, Funding, Data availability, Conflict of interest,
      Ethical approval — no statement left incomplete or truncated

## Process
- [ ] Open-items list delivered with the draft
- [ ] `[journal AI policy check needed]` present unless policy verified
- [ ] Any AI-use disclosure drafted ONLY from the user's confirmed actual
      AI use + the journal's verified official policy — never inferred,
      invented, or required
- [ ] Venue-agnostic drafts (when explicitly requested) labeled as such
- [ ] Human/supervisor review requirement stated
- [ ] Output kept local and private
