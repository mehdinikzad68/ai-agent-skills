# English Manuscript Rules (en, revised per PHASE 3A.1 + 3A.5)

Tags: [S] supervisor pattern / [J] journal convention / [I] improvement.

## General
- [S] Formal, information-dense register; no filler; compound explanatory
  sentences but disciplined length.
- [J] IMRaD unless the venue specifies otherwise; comply with venue format
  (headings, abstract type, reference style).
- [S] Tense: Methods past passive-dominant; Results past; Discussion and
  Conclusions present for general truths, past for this study's findings;
  occasional "we" for study actions.
- [S] AI-use disclosure, when one is needed: drafted ONLY from the user's
  confirmed actual use of AI tools (tool named, exact use stated, e.g.,
  English editing or code error-fixing) and the target journal's verified
  official policy. Never infer, invent, or require claims about how AI was
  used; never state a journal policy without checking the journal's
  official site.

## Abstract
- [S] **Default** move sequence: context → gap → method/finding →
  implication. Adjustable, not mandatory: follow the journal's abstract
  format when it differs (e.g., Background/Methods/Results/Conclusion).
- [S/J, confirmed example] The structured
  Objective/Methods/Results/Conclusion abstract is **venue-driven, not an
  author signature**: the 2022 Biotechnology Letters paper (DOI
  10.1007/s10529-022-03235-0) uses labeled Objective/Methods/Results/
  Conclusion sub-headings. Follow the venue's imposed structure; the corpus
  default remains the paragraph-form context → gap → method/finding →
  implication sequence when the venue does not impose one.
- [S] Include the key quantitative finding as supplied (`[data needed]` if
  missing).
- [S] End with the implication, sized to the evidence — prospective wording
  if not yet demonstrated.
- [J] **No citations in the abstract unless the venue explicitly permits or
  requires them.**
- [J] Keywords per journal style.

## Introduction
- [S] Funnel: broad context → prior knowledge (citation-dense) →
  methodological/analytical/coverage gap → "In this study …" close.
- [S] Gap types favored: methodological (accuracy, cost, accessibility),
  analytical (interference, resolution), or coverage (compound/class not
  yet profiled).
- [S] For basic plant-biotechnology/ecophysiology papers, frame significance
  around biological, methodological, or monitoring value — economic framing
  only when the field, venue, and data warrant it, never by default.
- [S] Final paragraph compact and concrete: what this study did + what it
  enables.
- [J] Historical/traditional-medicine framing only where the venue welcomes it.

## Materials and Methods
- [S] Numbered subsections; reproducibility-level parameters: instrument
  model, software versions, column specs, stepwise gradients, temperatures,
  quantities, n, units.
- [S] State the reason for non-obvious choices in-line.
- [J] Cite standard methods; describe any modification explicitly.
- [I] Unknown parameter → `[method detail needed]`; never supply a
  plausible value.

## Results
- [S] Observation-only prose; figure-led ("Fig. X shows …"); key table
  values read into text.
- [S] Quantitative statements: value + unit + dispersion + significance,
  exactly as supplied.
- [I] No interpretation, no literature comparison here — unless the journal
  uses a combined "Results and discussion" (then keep interpretive passages
  clearly distinguishable).
- [J] If the target venue combines Results and Discussion, mirror that
  section structure while clearly separating observation from
  interpretation within the prose.
- [S/J, confirmed example] The combined Results-and-Discussion
  section is a venue-driven, corpus-wide pattern — observed Tier A examples
  include the 2025 PCTOC and 2022 Biotechnology Letters papers. It is
  journal convention, not author signature: preserve it when the venue
  requires it, and keep observation, interpretation, limitation, and
  prospective application distinguishable within the prose.
- [J] Parallel subsection order across Methods, Results, Discussion.

## Discussion
- [S] Mirror the Results' subsection order; per finding: our result →
  literature comparison → agreement/disagreement → mechanism or practice.
- [S] Generic comparison formulas: agreement, contrast, attribution
  (reworded fresh every time; never reuse corpus sentences).
- [I] Dedicated explicit Limitations passage (not buried mid-paragraph).
- [I] Closing forward-look clearly marked as prospective.
- [I] Calibrate every claim to its evidence: direct wording for strong data;
  measured hedges for partial data.

## Conclusion
- [S] Short synthesis; no new data; no new citations.
- [S] Where warranted, one elevation move reframing the studied object by
  its demonstrated value — only if demonstrated.
- [I] One prospective application, explicitly prospective.

## Declarations / back-matter
- [J] Reproduce the venue-required transparency/declaration block
  completely — Acknowledgements, Author Contributions, Funding, Data
  availability, Conflict of interest, and Ethical approval — as applicable
  to the venue.
- [I] **Never reproduce a dangling or incomplete statement.** Every
  declaration must be complete (all required fields present) or explicitly
  gapped with the matching marker (e.g., `[author confirmation needed]`) —
  never a half-written sentence, truncated statement, or empty placeholder.
- [I] Declaration entries draft ONLY from user-supplied facts (funding IDs,
  author-contribution roles, ethics decisions); never invent them.

## Figures and tables
- [S] Self-contained captions: what is shown, symbol/color meaning, error
  bars, n; journal-required tags (e.g., color-online note) where applicable.
- [S] In-text narration for every figure and table.

## Response to reviewers
- [J] Point-by-point; quote each comment; answer directly; state the change
  and its location; new text quoted; polite, non-defensive. See
  `templates/response-to-reviewers-en.md`.
